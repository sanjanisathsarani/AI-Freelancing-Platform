# AI Projects and Services Freelancing Platform (PUSL2019)

## Project Overview
The AI Freelancing Platform is a full-stack web application and relational database system designed to connect clients and organizations with AI freelancers across Machine Learning, NLP, Computer Vision, and Generative AI.

## Project Structure
- `database/` – MySQL schema, sample data, and advanced SQL scripts (`ai_freelance_platform.sql`).
- `documentation/` – ER diagrams, relational mapping, 3NF normalization, and SQL testing documentation.
- `web_application/` – Complete PHP, HTML, CSS, and JavaScript source code (`assets/`, `client/`, `config/`, `freelancer/`, `includes/`, and `screenshots/`).

## Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP 8+ (PDO)
- **Database:** MySQL (via XAMPP / phpMyAdmin)

## Setup & Installation Instructions
1. Start **Apache** and **MySQL** in the XAMPP Control Panel.
2. Open `http://localhost/phpmyadmin` and create a database named `ai_freelance_platform`.
3. Import the SQL script(s) from the `database/` folder into `ai_freelance_platform`.
4. Place the contents of `web_application/` inside `C:\xampp\htdocs\ai_freelancing_platform`.
5. Open `http://localhost/ai_freelancing_platform/index.php` in your browser.
